# Keven Ohlew · Fallstudien

Die lange Fassung der vier Arbeiten, die auf
[keven-ohlew.com](https://keven-ohlew.com) in drei Zeilen stehen.

Der Unterschied ist Absicht. Die Hauptseite zeigt, WAS gebaut wurde.
Hier steht, WIE: die Lage davor, die Entscheidungen samt Begründung, die
Wege, die verworfen wurden, und was das gekostet hätte.

## Inhalt

- `index.html` · vier Fallstudien plus Positionierung, Werdegang, Belege,
  Zertifikate
- `impressum.html`, `datenschutz.html` · Pflichtseiten
- `404.html`

1. **Sicherheits-Scanner** · 18 Prüfungen, 14 technisch und 4 zur deutschen

   auch für nicht existierende Adressen einen Bericht aus. Check auf Anfrage.
2. **Gallery** · limitierte Foto-Editionen mit atomarer Nummernvergabe ·
   verkauft über KEOH030 · [gallery.keoh030.com](https://gallery.keoh030.com)
3. **Library** · ein Generator baut den ganzen Verlag aus einer Datenquelle ·
   [library.keven-ohlew.com](https://library.keven-ohlew.com)
4. **Sanierung** · Kundenarbeit, anonymisiert, vier Wochen, null Ausfall

## Bau

Statisches HTML, CSS und JS. GSAP und ScrollTrigger selbst gehostet,
Schriften selbst gehostet, keine Anfrage an einen fremden Host zur Laufzeit.
Ausgeliefert über GitHub Pages.

Der Zweiklang folgt derselben Regel wie keven-ohlew.com: der Rahmen bleibt
Nacht, der Lesekörper wird Tag. Die Klasse `.tag` sitzt auf dem Abschnitt,
nie auf `:root`.
